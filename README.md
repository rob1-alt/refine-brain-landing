# refine-brain-landing

Manifesto landing page for Refine — built in Next.js 16, sharing the
exact design language of the Refine Brain dashboard (cream `#FDFBF7`,
warm neutrals, orange accent `#F97316`, Alcyone display type).

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
